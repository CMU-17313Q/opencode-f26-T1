   failures. The "ignores unfinished tools, successful shells, and completed

2. Replacing the latest-user search with an oldest-user search caused the
   "uses the latest user context" property to fail, and Bun returned exit code 1.

These are deliberately introduced regressions, not bugs found in the original
implementation. No production source edits are part of this change. The final
33-test passing run above was performed after restoration.
