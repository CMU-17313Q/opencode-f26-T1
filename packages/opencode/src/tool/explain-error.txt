Use this tool when a tool call or command has failed and you are helping a student understand why, before you suggest or apply any fix. It returns evidence about the most recent failure in this session; if the student pasted an error instead, pass it as `error`. Use the result to write a student-friendly explanation of the likely cause, reading the related code when the evidence points to it. Follow the guidance in the result: do not state a guess as fact, and do not include the fix.
